# GitHub Lisans Sözleşmeleri ve Seçimleri
## MIT Lisansı
- Kod alınıp değiştirilebilir, projelere entegre edilebilir, ticari amaçla kullanılablir. Tek şart orjinal yzar belirtilmesi ve çökme vs. durumlarında sorumluluk kullanıcıdadır.
- Kısıtlamasız şejilde herkesin kullanmasını ve yayılmasını sağlar.
## GNU GPLv3
- Kod alınıp değiştirilebilir. Fakat kodu içeren yeni bir proje yazılıp dağıtılırsa, yeni projenin kaynak kodları tamamen açık kaynak olarak ve GPLv3 ile paylaşılmalıdır.
- Kodun satın alınıp ticari ürüne dönüştrülümesini engeller.
## Apache Lisansı 
- MIT lisansına benzer. Ekstra patent koruması içerir.
## No License 
- Telif hakkı tamamen kullanıcıdadır. Kod GitHub'da okunabilir fakat kopyalanamaz.
- Kod sadece kişisel veya ekibe özel ise seçilir.
